## 🍳 Features for Mom

* **Light Mode & Text Zoom (`A-`, `A`, `A+`):** Ultra-comfortable reading with warm cream tones and dark espresso contrast.
* **Countertop Kitchen Cook Mode:** Giant 26px+ step cards and step-by-step progress tracking for hands-on cooking.
* **Dynamic Serving Scaler (`[-] 1 Serving [+]`):** Increase servings effortlessly for family meals; all gram and tsp quantities scale live.
* **Batch Meal Prep Tips:** Every recipe includes Mom's storage & weekend prep strategy (freezing portions, soaking tips, keeping veggies crisp).
* **Built-in Kitchen Timer:** Interactive countdown with audible Web Audio chime.
* **Smart Paste / Import:** Easily paste any new recipe text to add it to the cookbook.
